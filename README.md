## Description

This is the official repository for [Transmogrification Lite](https://mod.io/g/baldursgate3/m/transmogrification-lite), a mod for Baldur's Gate 3 that allows you to combine the stats of one piece of equipment with the appearance of another.

The primary limitation of this mod is that each piece of equipment needs support to be specifically added for it, as opposed to it being able to work with everything by default like other transmogrification mods. The benefit to this mod's more limited approach is that it does not use Script Extender, and can therefore also be used on Mac and consoles.

This repository contains the mod's .pak file, a complete copy of the project's toolkit files, and an example project of how to extend this mod's support to more equipment.
